# Interface Language Audit Plan

This document tracks the systematic audit of the Streamlit interface in Portuguese, English and Spanish.

## Scope

The audit covers:

- visible Streamlit labels, headings, captions and messages;
- tabs, filters, selectors, metrics and download controls;
- research framing and methodological tables;
- values generated by supporting modules and displayed in the interface;
- preservation of source-language institutional names and evidence when translation would reduce traceability.

## Acceptance criteria

The interface is considered ready only when:

1. the automated audit reports no unwrapped public text;
2. Portuguese, English and Spanish are manually reviewed page by page;
3. no mixed-language sentence remains in interface-generated text;
4. source-language data are clearly distinguishable from interface text;
5. tests prevent new untranslated interface literals from being introduced.

## Current status

Audit infrastructure implemented. Full findings and corrections remain in progress.
