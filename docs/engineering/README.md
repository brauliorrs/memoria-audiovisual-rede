## Ordem de uso para releases

1. consultar a política de versionamento;
2. executar o checklist de release;
3. atualizar o changelog;
4. somente então criar tag e GitHub Release.

A versão de software não substitui snapshots científicos, versões de schema ou
identificadores de protocolos de validação.
