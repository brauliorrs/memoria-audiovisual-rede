# Checklist ERC

Este checklist deve ser usado como instrumento de maturacao, nao como confirmacao de prontidao imediata.

## 1. Enquadramento Cientifico

- [ ] Titulo e acronimo internacional definidos.
- [ ] Pergunta central em ingles fechada.
- [ ] Tres ou quatro perguntas derivadas.
- [ ] Hipoteses testaveis.
- [ ] Breakthrough cientifico formulado em uma frase.
- [ ] Estado da arte internacional mapeado.
- [ ] Lacuna cientifica demonstrada.
- [ ] Contribuicao teorica explicita.
- [ ] Painel principal e painel secundario justificados.

## 2. Plataforma como Infraestrutura

- [ ] Plataforma descrita como instrumento cientifico, nao como produto.
- [ ] Unidades de observacao definidas.
- [ ] Variaveis explicativas e dependentes definidas.
- [ ] Snapshots longitudinais implementados.
- [ ] Rotas instaveis e ausencias registradas como evidencias.
- [ ] Limites de coleta documentados.
- [ ] Indicadores preliminares calculaveis.
- [ ] Protocolo de reprodutibilidade escrito.

## 3. Metodologia

- [ ] Universo europeu delimitado.
- [ ] Criterios de inclusao e exclusao.
- [ ] Amostragem comparativa entre paises.
- [ ] Tipologia de regimes de visibilidade.
- [ ] Validacao manual das classificacoes.
- [ ] Plano longitudinal.
- [ ] Metodos estatisticos definidos.
- [ ] Estudos de caso qualitativos selecionados.
- [ ] Entrevistas estruturadas.
- [ ] Auditoria de encontrabilidade delimitada.
- [ ] Matriz de riscos cientificos.

## 4. Part I

Referencia provisoria 2027: maximo de cinco paginas para a Parte I da proposta cientifica, excluindo capa e referencias.

- [ ] Estado da arte em linguagem de painel.
- [ ] Pergunta e objetivos claros.
- [ ] Ideia original e criativa.
- [ ] Avanco da fronteira do conhecimento.
- [ ] O que sera mudado, aberto ou contestado no campo.
- [ ] Estrategia geral cientificamente convincente.
- [ ] Minima descricao tecnica da plataforma.

## 5. Part II

Referencia provisoria 2027: maximo de sete paginas para a Parte II da proposta cientifica, excluindo referencias.

- [ ] Metodologia detalhada.
- [ ] Work packages.
- [ ] Plano de cinco anos.
- [ ] Riscos e mitigacoes.
- [ ] Relacao entre metodologia, equipe e orcamento.
- [ ] Dados, etica e ciencia aberta.
- [ ] Nao repetir a Part I.

## 6. PI e Track Record

- [ ] CV ERC em ate quatro paginas.
- [ ] Ate dez contribuicoes centrais selecionadas.
- [ ] Papel do PI explicado em cada contribuicao.
- [ ] Evidencia de independencia cientifica.
- [ ] Publicacao principal submetida ou publicada.
- [ ] Reconhecimento internacional documentado.
- [ ] Capacidade de lideranca cientifica demonstrada.

## 7. Instituicao Anfitria

- [ ] Host institution europeia identificada.
- [ ] Departamento ou grupo de pesquisa definido.
- [ ] Escritorio ERC acionado.
- [ ] Condicoes de autonomia negociadas.
- [ ] Carta institucional viavel.
- [ ] Tempo minimo do PI no projeto e na Europa compatibilizado.
- [ ] Apoio GDPR, etica, dados e propriedade intelectual identificado.

## 8. Dados, Etica e Direito

- [ ] Data Management Plan preliminar.
- [ ] Avaliacao GDPR.
- [ ] Protocolo de coleta automatizada.
- [ ] Politica de direitos autorais.
- [ ] Estrategia de ciencia aberta.
- [ ] Criterios para snapshots e evidencias digitais.
- [ ] Plano de consentimento e anonimizacao para entrevistas.
- [ ] Plano de minimizacao de dados pessoais.

## 9. Go/No-Go

- [ ] Breakthrough convincente.
- [ ] Host comprometida.
- [ ] Track record minimamente competitivo.
- [ ] Part I testada com leitores externos.
- [ ] Plataforma produz evidencia longitudinal auditavel.
- [ ] Metodologia nao depende de promessas tecnicas vagas.
- [ ] Orcamento e equipe coerentes com cinco anos de pesquisa.
