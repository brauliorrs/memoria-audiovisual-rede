# Templates da camada infraestrutura digital

Arquivos vazios com cabeçalhos estáveis para preparar a futura entrada de dados curados.

- `institutions_template.csv`
- `providers_template.csv`
- `technologies_template.csv`
- `institution_technology_relations_template.csv`
- `procurement_contracts_template.csv`
- `data_flows_template.csv`
- `ai_systems_template.csv`
- `infrastructure_risks_template.csv`
- `evidence_registry_template.csv`

Estes arquivos não contêm resultados e não devem ser usados como saída da auditoria bruta. A integração futura deverá validar identificadores, estados controlados e integridade referencial antes de promover registros para a camada curada.
